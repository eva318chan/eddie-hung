# 孔令江 Eddie Hung — 個人網站

孔令江（Eddie Hung）的個人履歷網站：資深傳媒人、影視監製、新媒體策略家。單頁式深色主題網站，介紹其 30+ 年傳媒生涯、電視／新媒體／影視製作成就。

- 線上網址：https://eddie-hung.vercel.app

## 技術棧

- 單檔 HTML + 內嵌 CSS／JS（`index.html` 約 20 KB），無 framework、無 build step、無後端
- 深色主題＋金色點綴設計，sticky 導航列
- Hosting：Vercel（連接 GitHub `main` branch，push 即自動 deploy）

## 資料夾／檔案

| 路徑 | 說明 |
|---|---|
| `index.html` | 全站：所有內容、樣式、腳本都在呢一個檔 |

## 本地開發

直接用瀏覽器開 `index.html` 即可預覽，所見即所得。

## Deploy

Vercel 已連接本 repo 的 `main` branch：push 上 `main` 即自動 deploy 到 https://eddie-hung.vercel.app，無需手動操作。

## 維護注意事項

- 改履歷內容：直接改 `index.html` 內對應段落，push `main` 即更新。
- 保持繁體中文書面語風格，與現有文案一致。
